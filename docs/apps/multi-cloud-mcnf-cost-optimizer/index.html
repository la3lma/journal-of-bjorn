Caveats And Sources

This demo runs entirely in the browser. It does not fetch live prices, call cloud APIs, or optimize commitments, taxes, spot interruptions, capacity reservations, private discounts, or operation charges. Cloudflare R2 is modeled as object storage with free outbound transfer from R2; Cloudflare Workers and Workers AI compute are outside this first model. Telenor AI Factory is listed as a relevant Nordic sovereign AI-cloud provider, but public pricing was not found, so it is not included as a priced route.
